## Standard profile

The versioned `standard_md_v1` profile is the comprehensive, nonredundant public analysis path. New generally reusable methods should enter the registry and profile only after their contract, tests, documentation, and scientific limits are defined.

## Release gate

`v1.0` requires every standard-profile module to have reviewed scientific contracts, independent regression evidence, maintained documentation, and an explicitly supported status. Passing unit tests or one trajectory validation is necessary but not sufficient.
