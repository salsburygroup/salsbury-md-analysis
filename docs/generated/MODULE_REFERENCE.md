## Provenance and immutable manifests

- ID: `provenance_manifest`
- Stage: `1`
- Category: `core`
- Status: **experimental**

Validate project, system, output, and publication-lock manifests; compile explicit units, selections, and system/replica/segment identities; and produce deterministic input inventories with optional SHA-256 hashes.

Required inputs:

- project configuration
- system manifest
- declared units
- named selections

Declared outputs:

- validated manifests
- compiled analysis context
- context signature
- input inventory
- input hashes

Scientific limits:

- Provenance records technical lineage; it does not establish trajectory readability, convergence, population meaning, or scientific validity.

## Markov-state models

- ID: `markov_state_models`
- Stage: `9`
- Category: `md`
- Status: **experimental**

Build segment-safe transition models for every enabled complete clustering partition, select the best clustering model by kinetic validation, retain a separately reported FES-basin model, and report explicitly enabled noise-censored HDBSCAN only as a conditional sensitivity; Ward and quality-threshold are omitted unless they provide exact complete assignments over every observation; scan lag times, estimators, implied-timescale stability, Chapman-Kolmogorov consistency, time-blocked VAMP validation, and block-bootstrap uncertainty.

Required inputs:

- complete enabled clustering assignments

- physical frame timing
- segment identities
- lag, VAMP, CK, and bootstrap settings

Declared outputs:

- best geometric clustering
- best kinetically validated complete clustering model
- separate FES state model
- separate HDBSCAN core MSM sensitivity

## Topology-template hydrogen-bond discovery

- ID: `hydrogen_bond_discovery`
- Stage: `11D`
- Category: `md`
- Status: **experimental**

Automatically enumerate a frozen direct donor-hydrogen-acceptor dictionary from standard protein/nucleic-acid chemistry templates and explicit connectivity, with auditable provisional fallback for untemplated ligands; retain an explicit atom-index mode for publication locks, outcome-independent common-candidate harmonization for homologous systems, and optional chunked or fixed-width packed sparse output for large candidate universes.

- accepted trajectories

Declared outputs:

- candidate bond dictionary
- dense, sparse-list, or packed sparse frame-by-bond observations
- observed geometry
- directly readable primary occupancies
- exact packed sensitivity occupancies

Scientific limits:

- Packed sensitivity occupancies are exact nonzero count tables; absent candidate-cutoff records are evaluated zeros under the report's explicit-zero contract.
- This direct-bond module excludes water-mediated paths, which have a separate contract.
- Occupancy does not establish energetic or mechanistic importance.
