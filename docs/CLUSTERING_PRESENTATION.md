# Which clustering result appears first?

One primary partition is shown for each distinct view and scope: for example,
a pooled whole-complex comparison is not the same question as a per-system
or pooled-member analysis. Alternative methods remain searchable and expandable.
FES results remain separate. Geometric presentation selection does not replace
kinetic validation or choose an MSM.

New clustering reports evaluate each completed partition on the same bounded
sample, chosen from frame identities without using cluster labels. The sample
contains at most 1,024 observations. SHA-256 records identify the complete
transformed feature stream and the selected evaluation indices. Partitions must
use the same features, standardization, observations, Euclidean evaluation
metric, and no-noise coverage policy before their scores can be ranked together.
This changes neither the fit stride nor the full-frame assignments.

The highest comparable silhouette selects the primary display. Overlapping
geometric sampling-resolution bands are declared a tie; the fewer-state model,
then method name, breaks a display tie deterministically. This heuristic band
helps avoid overinterpreting small score differences; it is not a calibrated
confidence interval, an equivalence test, or biological uncertainty.
The method-specific fit scores remain visible but are not used as physical
effect sizes. If the sample misses a state, or comparisons have different
geometry or coverage, selection abstains instead of inventing a winner.

Older reports without this contract retain their existing scores. They may be
shown as unranked; a large historical silhouette is not enough evidence for a
new cross-method winner. Results are never recomputed merely to hide that gap.

The picker can highlight population changes or coupled interactions from a
selected partition. A high silhouette, many clusters, or a model-validation
status is method information, not a physical finding. Those records cannot
fill the opening page. FES findings, RMSF differences, contacts, ions, hydration,
and other physical results compete without category quotas. The target is
10–12 headlines, not a requirement to manufacture that many.

The bounded pair-distance matrix has at most 1,048,576 entries (8 MiB in
float64), plus library workspace. Evaluation is serial within each method.
Its process measurements are included in the method's existing resource record.

A sealed candidate index can also be replayed through the Python
`prioritize_findings` API with `candidate_snapshot` and its required
`expected_snapshot_sha256`, writing to a different output directory. This
reranks existing evidence without rerunning trajectories. The output records
its source hash and presentation-only purpose. An older index cannot supply
missing clustering comparisons; those partitions remain unranked.
