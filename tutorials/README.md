# Tutorials

Tutorials use small, redistributable inputs to show the complete user workflow.
They are teaching exercises, not substitutes for production sampling or
publication-specific protocols.

- [NEMO zinc-finger tutorial](nemo_zinc_finger/README.md): prepare and run a
  local, all-applicable analysis from a real Salsbury-group simulation subset
  containing a protein and its coordinated zinc ion, inspect the resource plan,
  and handle an insufficient memory ceiling without silent analysis changes.
- [Local and cluster workflow](local_and_cluster/README.md): install the command,
  inspect a plan, run it locally or through a reviewed Slurm profile, understand
  automatic recovery, and apply the final acceptance checks.
