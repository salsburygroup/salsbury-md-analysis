# Tutorials and how-to guides

The three NEMO tutorials teach the workflow with the same supplied structure,
topology, trajectory, and saved-frame interval. Choose the one that matches
where you will run it:

- [NEMO on a workstation](nemo_zinc_finger_workstation/README.md) runs the
  analysis locally.
- [NEMO on a Slurm cluster](nemo_zinc_finger_cluster/README.md) runs the same
  example through a site profile that you configure for your cluster.
- [NEMO on WFU DEAC](nemo_zinc_finger_deac/README.md) uses the Salsbury group's
  DEAC account, paths, partitions, and Conda installation.

The NEMO fixture is a teaching example, not evidence of converged sampling or a
scientific result.

Use the task-focused how-to guides for your own simulation files:

- [Analyze your own trajectories on a workstation](workstation/README.md).
- [Analyze your own trajectories on a Slurm cluster](cluster/README.md).

A tutorial supplies the example and expected checkpoints. A how-to guide starts
with your files and helps you complete one task. Command and configuration
details live in the [documentation index](../docs/index.md). Each page links to
its matching companion page; the complete set is in the
[interactive tutorial index](https://github.com/salsburygroup/salsbury-md-analysis-interactive/blob/main/tutorials/README.md).
