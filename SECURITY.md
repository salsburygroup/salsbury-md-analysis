# Security policy

## Supported release

Security corrections are applied to the current `0.1.x` release line. This is
experimental scientific software; a security correction does not by itself
promote a scientific method from `experimental` to `supported`.

## Reporting a vulnerability

Please report a suspected vulnerability privately through GitHub's security
advisory interface for this repository. If that interface is unavailable,
email `salsbufr@wfu.edu` with the subject “Salsbury MD Analysis security
report.” Do not place credentials, private trajectories, cluster paths, or an
unpatched exploit in a public issue.

Include the affected version or commit, operating system, a minimal reproducer
that contains no restricted data, the expected impact, and any known temporary
mitigation. Receipt will be acknowledged before public technical details or a
fix timeline are discussed.

Questions about scientific interpretation, convergence, or method validity are
not security vulnerabilities. They may be raised in an ordinary issue without
including private simulation data.
